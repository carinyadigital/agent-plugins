# `.agency` — delivery workspace

This folder holds planning, design, and backlog artefacts for this target repo. Practice skills read and write here after `/agency-hub:setup` binds the repo.

| Path | Purpose |
| --- | --- |
| `target.json` | Binding pointer to your agency instance (`name`, `instance`, `target`) |
| `product.md`, `roadmap.md`, `backlog.md` | Product and delivery artefacts |
| `work/` | Epic folders (`work/{epic}/tasks.md`, `design.md`, …) |
| `architecture/` | Solution docs and ADRs |
| `reviews/` | Ephemeral agent byproducts (gitignored) |

Committed files are team-shared. `reviews/` and `*.local.md` stay local.
