# Brand voice — review mode

Audit brand voice guidelines for completeness, consistency, and actionability.

Read [SKILL.md](../SKILL.md), [references/voice-constant-tone-flexes.md](../references/voice-constant-tone-flexes.md),
and [references/confidence-scoring.md](../references/confidence-scoring.md).

## Path

Resolve `<brand-dir>` per [brand-conventions.md](../../references/brand-conventions.md).
Default artefact: `<brand-dir>/brand-voice.md`. If the user names another path, review that file.

## Steps

1. Read brand-voice.md and optional brand-guide.md for boundary check
2. Verify voice constants, tone matrix, terminology, and examples
3. Flag open questions without recommendations
4. Check confidence scores match evidence quality
5. Recommend fixes prioritized blocking vs optional

## Output

Review report in chat.
