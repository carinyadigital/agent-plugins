# seo-specialist — Managed Agent cookbook

Claude CMA deployment for the SEO Specialist agent plugin. Recommendations via GitHub
issues; implementation handed to `/web-development:*` skills on engineering squads.

## Security tier

`standard` — source control and browser automation connectors; no write to production.

## Handoff

Technical SEO fixes and content changes are implemented by the `web-development` practice
— invoke `/web-development:implement` or open issues for the engineering squad.
