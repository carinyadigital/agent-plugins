# SEO Plugin

SEO practice for keyword research, technical audits, and content SEO review.
Recommendations flow to engineering squads via GitHub issues; Squad E does not
implement code fixes.

## Skills

| Skill | Mode | Description |
| ----- | ---- | ----------- |
| **keyword-research** | run | Topic keyword analysis → `docs/work/seo/` |
| **technical-seo-audit** | run | Production audit → GitHub issues |
| **content-seo-review** | review | SEO review on content seed PRs |

## Connectors

Prefer **github** (issues) and **playwright** (live site checks).

## Maintainers

```bash
python3 scripts/validate.py
```
